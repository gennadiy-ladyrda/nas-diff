# CORE-02

## 1. Задача
- Краткое название: Exact режим (точные дубли)
- Цель (что должно измениться в системе): Добавить полный цикл поиска exact-дубликатов по `blake3_full`.
- Ожидаемый результат в 1-2 предложениях: После scan формируются группы точных копий и считается потенциальная экономия места.

## 2. Scope
- Входит в задачу: Предгруппировка по размеру, хэширование BLAKE3, заполнение `exact_groups` и `exact_group_items`.
- Не входит в задачу: Similar режим и UI-сравнение.

## 3. Контекст
- Связанные документы/файлы: `docs/specification.md` FR-3, `database/schema.sql` exact таблицы.
- Текущие ограничения окружения (DSM6, Docker, пути NAS и т.д.): Обработка больших файлов без чтения целиком в память.
- Зависимости/интеграции: scanner output, DB-layer.

## 4. Требования
- Функциональные требования: Группа создается при `count >= 2`; `reclaimable_bytes` считается корректно.
- Нефункциональные требования (производительность, безопасность, UX): Хэширование потоковое, с ограничением конкурентности.
- Ограничения по безопасности данных: Только индексация; без file actions.

## 5. Критерии приемки
1. Точные дубли в тестовом датасете определяются без ложных совпадений.
2. В БД создаются корректные exact-группы.
3. Метрика reclaimable bytes совпадает с ожидаемой.

## 6. Проверки и тесты
- Какие проверки обязательны: Сверка хэшей и group cardinality.
- Какие тесты нужно запустить: Unit tests hashing + integration test exact mode.
- Что считается успешной валидацией: 0 false-positive на контрольном наборе.

## 7. Риски
- Основные риски: IO bottleneck при хэшировании больших файлов.
- Что делать при отклонении/ошибке: Ввести лимит параллелизма и батчевую обработку.

## 8. Уровень неопределенности
Оценка `U = (R + T + D + S) / 4`:
- `R` (requirements): 0.05
- `T` (technical): 0.08
- `D` (data/environment): 0.08
- `S` (safety impact): 0.03
- Итог `U`: 0.06

Если `U > 0.1`, перед реализацией нужны уточнения.

## 9. Формат результата
- Какие артефакты ожидаются (код, конфиги, docs): exact hasher/dedup модули, тесты, обновленная документация API.
- Какой отчет нужен в финале: статистика найденных exact-групп на тестовом наборе.
